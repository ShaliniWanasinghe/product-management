# Product Management System

A full-stack Product Management System built with **Angular** and **Spring Boot**.
This project is designed to practice modern frontend development, REST API integration, and CRUD-based product management.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ShaliniWanasinghe/product-management.git
```

```bash
cd product-management
```

### 2. Run the Frontend

```bash
cd product-management
npm install
npm start
```

The Angular application will run at:

```text
http://localhost:4200
```

### 3. Run the Backend

Open another terminal:

```bash
cd product-management-backend
```

Run the Spring Boot application using Maven:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
.\mvnw.cmd spring-boot:run
```

## 🔗 Project Architecture

```text
Angular Frontend
       ↓
   HTTP Requests
       ↓
Spring Boot REST API
       ↓
    MongoDB
```
